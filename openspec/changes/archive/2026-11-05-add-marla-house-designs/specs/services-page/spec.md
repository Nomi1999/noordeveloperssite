## MODIFIED Requirements

### Requirement: Building types
The What We Build page SHALL describe houses of all sizes, mainly 1 Kanal and 2 Kanal, with an entry each for 1 Kanal, 2 Kanal, 5 Marla and 10 Marla houses. Each entry SHALL have a render and a link to the matching design. The page structure SHALL allow adding further entries without layout changes.

#### Scenario: Adding a building type
- **WHEN** a new entry is added to the building types data
- **THEN** it appears on the page in the same layout as the existing entries

#### Scenario: Smaller houses listed
- **WHEN** a visitor reads the What We Build page
- **THEN** it has entries for the 5 Marla and 10 Marla houses, each linking to its design page
