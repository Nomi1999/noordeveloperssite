# Wordmark font comparison

Overlay of each candidate (best weight, tracking fitted to the original's word extents) on the original
wordmark: `wordmark-candidates.png` (rows: Saira Extra Condensed 900, Oswald 700, Antonio 400,
**Big Shoulders Display 500**, Teko 500, Barlow Condensed 500). Grey = same, red = candidate only, blue = original only.
Script: `brand/scripts/font-compare.mjs`.

Ink overlap (IoU): Big Shoulders Display 500 = 0.646, next best Saira Extra Condensed 900 = 0.424, Antonio 0.423,
Barlow Condensed 0.416. **Winner: Big Shoulders Display (OFL), 500 for the wordmark, 400 for the tagline.**
