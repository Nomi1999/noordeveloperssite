## Context

`brand/source/logo-traced.svg` (moved there by `site-foundation`) is a VTracer output on a 2060×2060 canvas. A render at 1000px shows the structure clearly. Its geometry is near-correct but noisy: the side houses aren't exact mirrors, the arc is lumpy, and the letters are traced outlines of an unknown condensed sans with stadium-shaped Os. Headless Chrome is available for rendering comparisons, and Node is available for scripts. See proposal.md for motivation and specs/brand-identity for requirements.

## Goals / Non-Goals

**Goals:**
- A hand-built master on a clean grid that every other variant is generated from.
- A repeatable build, so a tweak to the master regenerates every variant and icon.

**Non-Goals:**
- Redesigning the mark, changing proportions noticeably, or adding a color scheme beyond ink, paper and the accent.
- A full brand guidelines document. Usage rules live as short notes in `brand/README.md`.

## Decisions

### Rebuild by measurement, not by cleaning the trace
Render the original at 2000px, measure key coordinates (roof apexes, eaves, wall edges, chimney, arc endpoints and sag, monogram bounds), and hand-write a new SVG on a 1000-unit grid using simple primitives: polygons for the houses, a single cubic path for the arc, and stroked-then-outlined paths for the monogram.
*Alternative:* simplify the trace with path smoothing or `svgo` precision reduction. Rejected: it keeps the asymmetry and wobble, which are the defects we are fixing.

Only the left half of the house group is drawn. The right half is generated by mirroring with a `scale(-1,1)` transform about the center axis, then flattened, which guarantees symmetry. The center house and chimney are drawn whole, because the chimney is asymmetric by design.

### Monogram reconstruction
The "ND" monogram is redrawn with a single stroke width and consistent corner radii, keeping the three rising bars (building silhouettes) and the D's bowl with its inner counter. The stroke is expanded to fills at build time, so files contain no strokes and recolor via fill alone.

### Wordmark: match an OFL font, outline it, then fine-tune
Candidates are compared by overlay renders against the original wordmark: Barlow Condensed, Saira Extra Condensed, Antonio, Teko, Oswald and Big Shoulders Display, at weights that match the stem width. The closest match is set with even tracking, converted to paths with `opentype.js`, and then gets small manual corrections if needed (for example the R leg). The tagline uses the same family at a light weight with wide tracking, as in the original.
- If the winner is Barlow Condensed, `site-foundation`'s font choice stands.
- If it is another family, the display font token is switched to it so headings echo the logo. That is a one-line token change plus a package swap.

### One build script, many outputs
`brand/scripts/build-logo.mjs` reads `brand/master/` (mark parts plus wordmark and tagline paths) and composes:
- `brand/dist/logo-{stacked,horizontal,mark,monogram}[-accent].svg`, using `fill="currentColor"`. In accent versions the monogram group uses `fill="var(--noor, #F2A93B)"`.
- Optimized with `svgo` (precision 1–2, `removeViewBox: false`).
- Icons via `sharp`: monogram in paper on an ink square with 12% padding → `favicon.ico` (16/32), `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png` (512 with maskable-safe padding), plus `favicon.svg`. Plain SVGs can't respond to `prefers-color-scheme` in all browsers, so the favicon uses an ink background and is readable in both browser themes.

Outputs are copied into `public/` (icons, manifest) and `src/assets/brand/` (SVGs imported inline by components).

### Inline SVG in the site
`Logo.astro` takes `variant` and `accent` props and inlines the SVG with `aria-hidden="true"`. The surrounding link carries `aria-label="Noor Developers home"`. Inlining is what makes `currentColor` theming work and avoids an extra request.

### Review sheet
`brand/review/sheet.html` shows the original next to the redraw (stacked), a 50% opacity overlay, every variant on ink, paper and concrete backgrounds, and icons at 16, 32 and 180px. It is rendered to PNG with headless Chrome for approval.

## Risks / Trade-offs

- [No exact OFL match for the wordmark font] → Use the closest match plus manual glyph tweaks. The overlay check catches noticeable drift. If the original font is identified and licensed, swap it in.
- [The polish drifts too far from the original] → The overlay comparison in the review sheet, plus maintainer sign-off before the site uses the new logo.
- [Monogram detail breaks down at 16px] → The favicon is hand-checked at 16px. If needed, a dedicated small-size monogram with thicker strokes is produced. This is a standard optical adjustment, not a redesign.
- [Font switch ripples into site typography] → Limited to the display token. Re-check headings on the styleguide page.

## Migration Plan

Replace the temporary text wordmark in `Header.astro` and `Footer.astro` with `Logo.astro`. Swap in favicon and manifest links in the layout head. Regenerate `og-default.png` with the stacked lockup. Rollback is a revert of the component changes.
