## Purpose

Explains in one page everything Noor Developers build and the two ways a customer can work with them.

## Requirements

### Requirement: Building types
The What We Build page SHALL describe houses of all sizes, mainly 1 Kanal and 2 Kanal, with an entry each for 1 Kanal and 2 Kanal houses. Each entry SHALL have a render and a link to the matching design. The page structure SHALL allow adding further entries without layout changes.

#### Scenario: Adding a building type
- **WHEN** a new entry is added to the building types data
- **THEN** it appears on the page in the same layout as the existing entries

### Requirement: Two offerings in detail
The page SHALL explain both offerings:
- **Buy a Noor home**: Noor buys the plot, designs, builds and finishes the house, then sells it.
- **Build on your plot**: Noor designs and architects the building around the client's plot and needs, builds it and finishes it.

Neither SHALL mention prices, payment terms, availability, approvals or permits.

#### Scenario: Offering details
- **WHEN** a visitor reads the offerings section
- **THEN** each offering explains what Noor does from start to finish in plain language

### Requirement: Fully finished promise
The page SHALL show the full shared fully finished checklist, grouped by area (structure and services, interiors, kitchen and bathrooms, outside). It SHALL state that only furniture is not included.

#### Scenario: Exclusion stated
- **WHEN** a visitor reads the checklist
- **THEN** it says clearly that furniture is not included

### Requirement: Page call to action
The page SHALL end with Call and WhatsApp actions using a message that mentions the visitor's interest in building with Noor.

#### Scenario: WhatsApp from What We Build
- **WHEN** the visitor uses the WhatsApp action on this page
- **THEN** the prefilled message mentions building with Noor Developers
